# i3-config

My personal [i3](https://i3wm.org/) window manager configuration — a tiling window manager for X11.

This repo contains my i3 setup: the main `config` file (keysym-based) and the `config.keycodes` template (keycode-based, generated by `i3-config-wizard`).

## Features

- **Modifier key:** `Mod1` (Alt)
- Vim-style focus keys (`j` / `k` / `l` / `;`) plus arrow keys
- 10 workspaces with quick switching
- Resize mode for precise window sizing
- Scratchpad support
- Clipboard screenshots with `maim` + `xclip`
- Volume controls via `pactl` (PulseAudio)
- Network tray (`nm-applet`), screen lock on suspend (`xss-lock` + `i3lock`)

## Dependencies

| Package | Purpose |
|---|---|
| `i3` | The window manager itself (includes `i3bar`, `i3-msg`, `i3-nagbar`, `i3-sensible-terminal`, `i3-config-wizard`) |
| `i3status` | System status information for the bar |
| `dmenu` | Application launcher (`dmenu_run`) |
| `dex` | XDG autostart support |
| `xss-lock` | Locks the screen before suspend |
| `i3lock` | Screen locker used by `xss-lock` |
| `network-manager-applet` | Network tray icon (`nm-applet`) |
| `pulseaudio-utils` / `libpulse` | Provides `pactl` for volume control |
| `maim` | Screenshot capture |
| `xclip` | Clipboard integration for screenshots |
| `xdotool` | Active-window screenshot support |
| `ttf-dejavu` / `fonts-dejavu-core` | Monospace font (recommended) |

## Installation

### 1. Install dependencies

**Arch Linux:**
```bash
sudo pacman -S i3 i3status dmenu dex xss-lock i3lock \
  network-manager-applet libpulse maim xclip xdotool ttf-dejavu
```

**Debian / Ubuntu:**
```bash
sudo apt install i3 i3status dmenu dex xss-lock i3lock \
  network-manager-applet pulseaudio-utils maim xclip xdotool fonts-dejavu-core
```

**Fedora:**
```bash
sudo dnf install i3 i3status dmenu dex xss-lock i3lock \
  nm-applet pulseaudio-utils maim xclip xdotool dejavu-sans-mono-fonts
```

### 2. Clone this repo

```bash
git clone https://github.com/AboalfazlForooghi2004/i3-config.git
cd i3-config
```

### 3. Install the config

```bash
mkdir -p ~/.config/i3
cp config ~/.config/i3/config
```

> **Note:** The clipboard screenshot bindings use the `$mod` variable, which is
> defined in `config.keycodes` but not in `config`. If you use those bindings,
> add this line near the top of your `~/.config/i3/config`:
>
> ```
> set $mod Mod1
> ```

### 4. (Optional) Keycode-based layout

If you prefer a config that follows your physical keyboard layout regardless of
the active language layout, use the keycode template instead:

```bash
cp config.keycodes ~/.config/i3/config
```

Or run `i3-config-wizard` to generate a keysym-based config for your current layout.

### 5. Start i3

Log out, then select **i3** from your display manager's session menu.
If you use `startx`, make sure your `~/.xinitrc` contains:

```bash
exec i3
```

## Keybindings

### Basics

| Keys | Action |
|---|---|
| `Mod1 + Return` | Open terminal |
| `Mod1 + Shift + q` | Kill focused window |
| `Mod1 + d` | Open `dmenu` launcher |
| `Mod1 + Shift + c` | Reload config |
| `Mod1 + Shift + r` | Restart i3 in place |
| `Mod1 + Shift + e` | Exit i3 (with confirmation) |

### Focus & movement

| Keys | Action |
|---|---|
| `Mod1 + j / k / l / ;` | Focus left / down / up / right |
| `Mod1 + ← / ↓ / ↑ / →` | Focus left / down / up / right |
| `Mod1 + Shift + j / k / l / ;` | Move window left / down / up / right |
| `Mod1 + Shift + ← / ↓ / ↑ / →` | Move window left / down / up / right |

### Layout

| Keys | Action |
|---|---|
| `Mod1 + h` / `Mod1 + v` | Split horizontal / vertical |
| `Mod1 + f` | Toggle fullscreen |
| `Mod1 + s` / `w` / `e` | Stacked / tabbed / toggle split layout |
| `Mod1 + Shift + space` | Toggle tiling / floating |
| `Mod1 + space` | Toggle focus between tiling / floating |
| `Mod1 + a` | Focus parent container |
| `Mod1 + r` | Enter resize mode |

### Workspaces

| Keys | Action |
|---|---|
| `Mod1 + 1 … 0` | Switch to workspace 1–10 |
| `Mod1 + Shift + 1 … 0` | Move window to workspace 1–10 |
| `Mod1 + Shift + minus` | Move window to scratchpad |
| `Mod1 + minus` | Show / hide scratchpad window |

### Screenshots (to clipboard)

| Keys | Action |
|---|---|
| `Ctrl + Print` | Full screen |
| `Ctrl + Mod1 + Print` | Active window |
| `Ctrl + Shift + s` | Select area |

### Media keys

| Keys | Action |
|---|---|
| `XF86AudioRaiseVolume` / `LowerVolume` | Volume ±10% |
| `XF86AudioMute` | Toggle mute |
| `XF86AudioMicMute` | Toggle mic mute |
